# Aegolith v0.1: design

Date: 2026-11-24. Owner: Mohsin (ergasterion-dev). Status: approved by the owner up front ("all approved, work
autonomously"); every decision below that the owner did not state is marked **[call]** with its reason.

## 1. Intent and the why

Aegolith (Greek *aigis*, the shield of Zeus and Athena, + *lithos*, stone: "the shield stone"; renamed from Pylolith on 2026-11-24 by owner decision) is an open-source **web application firewall library
for Go JSON APIs**. It runs inside the API process as middleware, inspects each request, and blocks (or, in monitor mode,
only reports) injection attacks and protocol abuse.

Why it exists, from measurements on a real production API (ExampleCo, Go + Fiber v2 on Kubernetes, server-side p95 target under
20 ms), 2026-11-24 (ExampleCo `example-infra/load-tests/waf/README.md`):

- Every option that runs the full OWASP Core Rule Set (CRS) on every request costs **1-2 ms of CPU per request** or more:
  native Coraza v3.8.1 (0.8 ms GET, 1.9 ms JSON POST on an Apple M4 Pro core), CrowdSec AppSec with CRS (saturates at
  about 300 req/s per core), Azure Front Door Premium managed rules (+2.4-2.9 ms in region, USD 330/month).
- The open-source Traefik Coraza plugin (WebAssembly) was OOM-killed at 1 GiB, collapsed at 300 req/s, and returned 500
  on every request after memory corruption.
- Edge WAFs cost money (Front Door Standard USD 35/month with custom rules only, Premium USD 330) or route Indian users
  through Singapore (Cloudflare Free/Pro: +160-190 ms per call).
- A JSON API does not need 600 generic regex rules: most fields have a known shape (UUID, integer, enum). A value that
  matches its shape cannot carry SQL injection. Heavy detection is only needed on the few free-text fields.

So: a WAF that knows the API. It checks protocol and request shape first (cheap), then runs proven attack detectors
(libinjection for SQLi/XSS, a curated rule set for the rest) only where text is free. Target cost: **tens of
microseconds per request**, not milliseconds; **zero infrastructure**; safe to run in monitor mode in production first.

Success for v0.1:
- On the 107-attack / 32-legitimate-request corpus from the ExampleCo tests (it becomes this repo's `testdata/corpus`),
  block at least as many attacks as tuned Coraza PL2 (99/107) **with 0 false positives** on the legitimate set.
- p99 cost per typical request (search GET, JSON cart POST) under 50 µs on one core, measured by `go test -bench`.
- Drop-in middleware for `net/http` and Fiber v2, usable by ExampleCo's backend.
- A project an outsider can read, run, and contribute to (README, docs, tests, Apache-2.0).

## 2. Goals, non-goals, anti-goals

Goals (v0.1):
1. Engine library: normalized request in, decision out (allow / block / monitor), with matched rules and locations.
2. Protocol checks: method allowlist, content-type allowlist, body size limit, CR/LF/NUL in path or headers, encoded and
   double-encoded path traversal, request-smuggling header combinations.
3. Attack detectors over request values: SQLi and XSS (libinjection), OS command injection, path traversal / LFI in values,
   remote file inclusion and SSRF schemes and cloud metadata addresses, Log4Shell/JNDI, server-side template injection,
   CRLF injection in values, NoSQL operator keys and prototype-pollution keys in JSON, XXE markers (only if XML is
   allowed), scanner user agents and well-known scanner paths.
4. Route policies (the API-aware part): declare routes (method + path pattern) and, per route, the expected path params,
   query params and JSON body fields with types (`uuid`, `int`, `number`, `bool`, `enum`, `string` with max length and
   optional pattern, `email`, `phone`, `text`). Typed fields are validated by type and skipped by the heavy detectors;
   `text` fields and anything untyped get the full detector set. Unknown routes and unknown fields: configurable action.
5. Modes: `enforce` and `monitor` globally, with per-route and per-rule overrides; exclusions by rule ID x route x field
   (the fix for false positives such as `House #12` or `price<500`).
6. Adapters: `net/http` middleware (core module, stdlib only) and Fiber v2 middleware (separate Go module).
7. Observability: a decision hook (for logging and metrics), redacted snippets only (never log full values: PII).
8. Configuration from Go code and from a JSON file (stdlib `encoding/json`).
9. Quality: unit tests per detector, the corpus test with the targets above, fuzz tests (no panics, bounded time),
   benchmarks, `make ci`.

Non-goals (v0.1, do not build):
- Response inspection, bot challenges, CAPTCHA, rate limiting, IP reputation (ExampleCo already rate-limits; CrowdSec
  can add reputation later).
- A ModSecurity/SecLang rule parser or CRS compatibility.
- Generating route policies from Go structs or OpenAPI (v0.2: the differentiator, but it needs v0.1's policy model first).
- Fiber v3, Gin, Echo, Chi adapters (v0.2; Chi/Gorilla work via `net/http` already).
- A dashboard, a hosted service, a sidecar proxy binary.
- GitHub Actions (org rule): CI is `make ci` plus a git pre-commit hook script.

Anti-goals (failure even if it technically works):
- Blocking real customers. A false positive is worse than a missed probe that the backend would 404 anyway.
- Adding milliseconds. If a feature costs more than the budget, it is off by default or out.
- Becoming a CRS clone: generic rules only where the field is free text.
- Crashing the host process: no panics escape the middleware; internal errors follow a configured fail-open/fail-closed.

## 3. Constraints

- Go 1.25 (ExampleCo backend's version) **[call]**: the newest Go the owner's machine has; Kritolith targets 1.26.
- Module `github.com/ergasterion-dev/aegolith`, GitHub org `ergasterion-dev`, public repo **[call]**: open source was the
  owner's explicit intent.
- License **Apache-2.0 [call]**: the org's convention (Kritolith), it is the license of Coraza and the CRS we take ideas and
  rules from, and its patent grant suits a security library. Dependencies must be Apache-2.0, BSD or MIT compatible.
  Never copy code from GPL/AGPL projects (SafeLine, BunkerWeb): ideas only.
- Core module dependencies: standard library + `github.com/corazawaf/libinjection-go` (BSD-3-Clause) only. Fiber lives in
  `adapters/fiberv2` as its own module so the core never pulls Fiber/fasthttp.
- Fiber v2 (`github.com/gofiber/fiber/v2`, fasthttp underneath): the adapter must copy what it needs out of the fasthttp
  context (fasthttp reuses buffers after the handler returns).
- No GitHub Actions anywhere (owner's global rule).

## 4. Approaches considered

| Approach | Trade-off | Verdict |
|---|---|---|
| A. Wrap Coraza + CRS in a nicer API (Fiber v2 adapter, exclusions) | Proven rules, ModSecurity compatible, but 1-2 ms CPU per request and CRS false positives: exactly the cost we measured and rejected | Rejected as the core; Coraza can be an optional "heavy" engine for risky routes later |
| B. Own engine: protocol checks + route policies + targeted detectors (libinjection + curated rules) | Cheap and API-aware; needs its own careful tests and corpus; fewer rules than CRS | **Chosen** |
| C. Sidecar/edge proxy (Caddy/HAProxy + Coraza, or SafeLine) | Language agnostic, but an extra hop, extra pods/VMs, same CRS cost, SafeLine is GPL | Rejected for v0.1 |

Approach B reuses, rather than reinvents: libinjection-go (dependency) for SQLi/XSS, CRS rules as a **reference** for the
curated patterns (Apache-2.0: patterns adapted from CRS keep attribution in `NOTICE` and in the rule's comment), and the
Fiber Coraza middleware (MIT) as a reference for the Fiber integration shape.

## 5. Design

### 5.1 Packages (core module)

```
aegolith.go            public API: New(cfg) (*Firewall, error), (*Firewall).Inspect(*Request) Decision
request.go             Request: Method, RawPath, Path, Query (url.Values), Header (http.Header), ContentType,
                       Body []byte, RemoteAddr, Route (template string, "" if unknown), PathParams map[string]string
decision.go            Decision{Action (Allow|Block), Monitored bool, Matches []Match}; Match{RuleID, Category, Severity,
                       Location (path|query|header|body|method|protocol), Field, Snippet (redacted, max 64 bytes)}
config.go              Config + JSON loading + validation (fail fast at startup with clear errors)
internal/normalize/    URL decode once + detect double encoding, path cleaning, JSON walking into (pointer, value) pairs,
                       header value extraction; bounded (max depth, max fields, max value length inspected)
internal/protocol/     method/content-type/size/CRLF/NUL/traversal/smuggling checks
internal/detect/       detectors: sqli, xss (libinjection), cmdi, lfi, rfi/ssrf, jndi, ssti, crlf, nosql, protopollution,
                       xxe, scanner; each a pure func(value string) (hit bool, ruleID string)
internal/policy/       route matching (method + segment patterns with :params and a trailing *), field type validation
internal/engine/       pipeline: protocol -> route policy -> detectors on the right values -> exclusions -> mode -> decision
httpwaf/               net/http middleware (stdlib only)
adapters/fiberv2/      separate module: Fiber v2 middleware
testdata/corpus/       attacks.jsonl and legit.jsonl (from the ExampleCo suite), each line: name, category, request
```

**[call]** Package names and file split are the builder's, as long as the core stays stdlib + libinjection-go.

### 5.2 Pipeline (cheap first, stop early only when blocking in enforce mode)

1. **Protocol**: method in allowlist (default GET HEAD POST PUT PATCH DELETE OPTIONS), content type in allowlist (default
   `application/json`, `application/x-www-form-urlencoded`, `multipart/form-data`; requests without a body need none),
   body size (over the limit: block by default, owner ruling 2026-11-25; the part past the limit is not inspected),
   CR/LF/NUL in path or header values, raw path traversal (`../`, `..%2f`, `%252e`, backslash forms),
   `Transfer-Encoding` with anything but `chunked`, or both `Transfer-Encoding` and `Content-Length`.
2. **Route policy** (when routes are configured): match method + path to a declared route. Unknown route -> configured
   action (default `monitor`: report, do not block **[call]**: unknown-route blocking breaks clients after every new endpoint
   until the policy is updated). Validate typed params/fields; a type mismatch is a match in category `schema`.
3. **Detectors** on the values that need them: every value of an untyped input (no policy, or a field not declared and
   `unknownFields` = `inspect`), and every `text` field. Values: path segments, query values (and keys), JSON string
   values and keys, form values, cookie values, `User-Agent`, `Referer`, and configured extra headers. JSON numbers and
   booleans are not text-scanned. NoSQL and prototype-pollution detectors look at JSON keys.
4. **Exclusions**: drop matches for (rule ID or category) x (route or `*`) x (field or `*`).
5. **Mode**: enforce -> any remaining match with action `block` blocks; monitor -> allow, `Monitored = true`, matches kept.

Decision is deterministic for a given config and request (apart from the measured Duration). No global state; the Firewall is safe for concurrent use.

### 5.3 Detection rules

- SQLi and XSS: `libinjection-go` (`IsSQLi`, `IsXSS`) on the value, plus once more on the URL-decoded value when it differs.
- Command injection: shell metacharacter followed by a known command or path (`;`, `|`, `&&`, `` ` ``, `$(`), reverse-shell
  markers (`/dev/tcp/`, `bash -i`, `nc -e`), Windows `cmd`/`powershell`, Shellshock `() {`. Must not flag plain prose with a
  semicolon or ampersand (`milk & bread`, `Gate code 1234 & leave at door`).
- LFI: traversal sequences in values, sensitive file names (`/etc/passwd`, `/etc/shadow`, `/proc/self/`,
  `serviceaccount/token`, `win.ini`), NUL byte.
- RFI/SSRF: URL schemes `file:`, `php:`, `gopher:`, `dict:`, `ldap:`, `jar:`, `expect:`, `data:text/html`; cloud metadata
  hosts (`169.254.169.254`, `metadata.google.internal`, `[fd00:ec2::254]`); `http(s)://` to loopback or private ranges only
  in fields not declared as URLs **[call]**: a free-text field legitimately contains links.
- Log4Shell: `${jndi:` with nested-lookup obfuscation (`${${lower:j}ndi:`, `${::-j}`).
- SSTI: `{{ ... }}` containing code-like content (`__class__`, `config`, `.Env`, `|`), `${T(`, `#{`, `<%= %>`, `{% %}`.
- CRLF in values: CR or LF followed by a header-like token.
- NoSQL: JSON object keys starting with `$` (`$gt`, `$ne`, `$where`); prototype pollution: keys `__proto__`,
  `constructor`+`prototype`.
- XXE: only when XML is allowed: `<!DOCTYPE` with `<!ENTITY` or `SYSTEM`/`PUBLIC`.
- Scanner: user-agent tokens (sqlmap, nikto, nuclei, masscan, nmap, zgrab, wpscan, dirbuster, gobuster, ffuf, acunetix,
  nessus, openvas) and well-known probe paths (`/wp-admin`, `/phpmyadmin`, `/.env`, `/.git/`, `/actuator`, `/server-status`).

Rule IDs: stable strings `AEG-<CATEGORY>-<NNN>` (e.g. `AEG-SQLI-001`). Each rule has a default severity and action.

### 5.4 Configuration

Go:
```go
fw, err := aegolith.New(aegolith.Config{
    Mode: aegolith.ModeMonitor,
    Routes: []aegolith.Route{{
        Method: "POST", Path: "/api/v1/cart/items",
        Body: map[string]aegolith.Field{"product_id": {Type: "uuid"}, "qty": {Type: "int", Min: 1, Max: 99},
                                       "note": {Type: "text", MaxLen: 500}},
        UnknownFields: aegolith.ActionBlock,
    }},
    Exclusions: []aegolith.Exclusion{{Rule: "AEG-SQLI-*", Route: "GET /api/v1/products/search", Field: "query.q"}},
})
```
JSON file: the same structure (`aegolith.LoadConfig(path)`). Field paths: `query.<name>`, `path.<name>`, `header.<name>`,
`body.<json.pointer.like.dotted>` (arrays as `items[]`).

### 5.5 Adapters

- `httpwaf.Middleware(fw, opts) func(http.Handler) http.Handler`: reads the body up to the limit and restores it for the
  next handler, builds the Request, calls Inspect, on block writes the block response, calls the decision hook.
- `adapters/fiberv2.New(fw, opts) fiber.Handler`: copies method, path, query, headers and body out of `*fiber.Ctx`
  (fasthttp buffers are reused), route template from `c.Route().Path` when available.
- Block response: `403`, `application/json`, `{"error":"request blocked","request_id":"..."}`; no product name or rule in
  the response (no fingerprinting); customizable handler.
- Panics inside Aegolith are recovered; `FailOpen` (default true **[call]**: an availability bug in a security layer must
  not take the API down) decides allow vs 500, and the hook is told.

### 5.6 Observability

`OnDecision func(*Request, Decision)` hook; a ready helper that logs with `log/slog` at warn for blocks and info for
monitor matches, fields: route, rule IDs, categories, locations, redacted snippets, latency. No metrics dependency in core
(users wire Prometheus/Datadog in the hook).

### 5.7 Performance budget

- Typical requests (the corpus's legit set) p99 under 50 µs on one core; benchmark in `bench_test.go`, results in README.
- Inspection bounds: max body bytes inspected (default 1 MiB), max JSON depth 32, max fields 1,000, max value length scanned
  8 KiB (longer values: scanned prefix + a `AEG-PROTO-` match if configured), all configurable.

## 6. Testing

- Unit tests per detector: true positives and the listed false-positive guards (prose with `&`, `;`, `#`, `<`, `%`, Urdu and
  Hindi text, names with apostrophes).
- Corpus test: `testdata/corpus/attacks.jsonl` (107) and `legit.jsonl` (32 + new realistic cases); the test asserts
  blocked >= 99 and false positives = 0 and prints a per-category table; misses listed in the README honestly.
- Fuzz tests: engine `Inspect` with random requests (no panic, bounded time); normalize/JSON walker.
- Adapter tests with `httptest` and Fiber's `app.Test`.
- Benchmarks: no-firewall baseline, GET search, JSON POST, worst case large JSON.

## 9. Decisions after the builder check (all **[call]**, owner away and pre-approved)

1. **Corpus gate configurations.** Two runs, both `ModeEnforce`, **no exclusions** (exclusions are for users; allowing them in
   the gate would make "0 false positives" meaningless):
   - **Generic**: no routes; every input is untyped and gets every detector. Gate: blocked >= 95/107, false positives = 0/32.
   - **API-aware**: a ExampleCo-shaped policy in `testdata/corpus/example-api-policy.json` (e.g. `product_id` uuid, `qty` int,
     search `q` text, review/note/address fields text, `image_url` a URL-typed field, `UnknownFields: block` on the cart route).
     Gate: blocked >= 99/107, false positives = 0/32. A `schema` match with action block counts as blocked.
   - "Blocked" means `Decision.Action == Block`. Requests the corpus marks `never-reaches-app` (Go's HTTP server would reject
     them first, e.g. the bad `Transfer-Encoding`) are still sent to `Inspect` and counted normally.
   - The legitimate set grows beyond the 32 with more realistic ExampleCo traffic (prose with `&`, `;`, `#`, `<`, `%`, Urdu,
     Hindi, apostrophes, URLs in review text, decimal prices); all must pass in both configurations.
2. **The detector list is not closed.** Add targeted, low-false-positive detectors for the uncovered corpus cases:
   code injection (`<?php`, `eval(`/`assert(` with `base64_decode`, Node `require('child_process')`/`process.mainModule`,
   Java serialized-object magic `rO0AB`/`aced0005`), LDAP injection (`*)(`, `)(|(`, `)(&(` filter breakers), backup and
   editor-file probes in the path (`.bak`, `.old`, `.orig`, `.swp`, `~`, `.save`), NoSQL operators in query keys
   (`[$ne]`, `[$gt]`, ...), session identifiers in the URL (`PHPSESSID=`, `JSESSIONID=`, `ASPSESSIONID`). Each new rule
   ships with its false-positive guard tests. "Not a CRS clone" still holds: no generic catch-all regexes.
3. **Default rule actions.** Every attack detector, scanner user-agent and probe-path rule: severity per category, action
   **block**. Unknown route: **monitor**. Over-long value (beyond the inspected prefix): **monitor**. Schema mismatch on a
   declared field: **block**. Unknown field: per-route `UnknownFields` (default **monitor**, the corpus policy sets block on
   the cart route).
4. **Scope.** v0.1 includes creating the public repo `ergasterion-dev/aegolith` and pushing (the owner asked for it).
   Wiring into `example-backend` is **out** of this session (owner: keep the work in the open-source folder).
   Route matching is always Aegolith's own (Fiber v2 global middleware cannot see the matched route); the Fiber adapter
   passes method + path only.
