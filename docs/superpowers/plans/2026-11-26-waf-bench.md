# WAF Bench Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A reproducible bench that measures Aegolith's detections, false positives and behaviour under load against test sets the project did not write, locally and against a remote deployment the operator owns.

**Architecture:** A separate Go module under `bench/` with one command, `aegobench`. Importers turn each source into JSONL case lines; cases are merged into distinct requests, sent over HTTP to a small target server wrapped by `httpwaf`, and scored by joining the target's access and decision logs by request ID. Remote mode reuses the same cases and scoring with an allow-list and automatic stops.

**Tech Stack:** Go 1.25, `net/http`, `httpwaf`, `gopkg.in/yaml.v3` (bench module only).

**Spec:** `docs/superpowers/specs/2026-11-26-waf-bench-design.md`

## Global Constraints

- This repository is public: no private product names, hosts, IPs, customer data or local paths in code, test data, docs or commit messages.
- The core module keeps its single dependency. Bench code and its dependencies live only in `bench/` (module `github.com/ergasterion-dev/aegolith/bench`, `replace github.com/ergasterion-dev/aegolith => ../`).
- No change to detectors, rules or any file outside `bench/`, `Makefile`, `.gitignore`, `README.md`, `CLAUDE.md` (layout and command table) and `docs/`.
- Third-party sets are fetched at a pinned commit with the licence recorded, never copied into the repository. A source whose licence does not allow this use is left out and listed.
- Downloaded third-party files are untrusted data: parse them, never execute them.
- Outbound callback hosts in payloads are rewritten to `callback.invalid` before encoding.
- Held-out: SHA-256 of the decoded payload, 30%, unsalted. Held-out cases are never listed individually.
- One case is one distinct request after encoding and placement. Repeats never change a rate.
- `near-miss` cases never enter the false positive rate.
- Never log full request values; reuse the library's redaction (decision records carry rule IDs, not payloads).
- Commit to `main` after each task and push. Conventional Commits. No branches.
- Every task: `gofmt`, `go vet ./...` and `go test ./...` pass in `bench/`, and `make ci` still passes at the root.

## Review Focus

1. A payload with bytes that are illegal in a URL or header: expect outcome `rejected` or `not-sent` with a reason, never `passed`, never a crash.
2. A truncated or partly written log line (run killed): expect the affected case to be `unknown`, not `passed`, and the join to continue.
3. A target that answers with a redirect: expect the runner not to follow it, so nothing reaches another host.
4. A callback host in upper case, with a port, with user info, or in a protocol-relative URL: expect it rewritten before any encoder runs.
5. A remote target file whose host differs from `--confirm-host` only by port or user info: expect a refusal before any request.

### Task 1: Module, case model and baseline importer

**Interfaces (Produces):**
```go
package cases
type Expected string
const (Attack Expected = "attack"; Legit Expected = "legit"; NearMiss Expected = "near-miss")
// Line is one JSONL line: the corpus line format plus source fields.
type Line struct {
    Name, Category, Kind, Method, Path string
    Query       [][]string
    RawQuery    string            // json "raw_query"; used instead of Query when set
    Headers     map[string]string
    ContentType string            // json "content_type"
    Body        string
    BodyBase64  string            // json "body_base64"
    Source      string            // json "source"
    SourceCaseID string           // json "source_case_id"
    Expected    Expected          // json "expected"
    Payload     string            // json "payload"; decoded payload, may be empty
    Placement   string            // json "placement": path|query|header|body|json|raw
    Encoder     string            // json "encoder"
}
type SourceRef struct{ Source, CaseID string }
type Case struct {
    ID string; Sources []SourceRef; Category string; Expected Expected
    Payload, Placement, Encoder string
    Method, Path, RawQuery string; Headers map[string]string; Body []byte
}
func FromLine(l Line) (Case, error)          // encodes Query pairs as corpus_test.go does
func Merge(cs []Case) (merged []Case, conflicts []Case) // same request -> one Case, all Sources; differing Expected -> conflicts, excluded
func Split(c Case) string                    // "baseline", "dev" or "held-out"
func ReadLines(r io.Reader) ([]Line, error); func WriteLines(w io.Writer, ls []Line) error
package baseline
func Import(corpusDir string) ([]cases.Line, error)  // Source "baseline"
```
`ID` is hex SHA-256 over method, path, raw query, sorted lower-cased headers and body. `Split` returns `baseline` when every source is `baseline`; otherwise it hashes `Payload` (or `ID` when empty) and returns `held-out` when `binary.BigEndian.Uint64(sum[:8])%100 < 30`.

### Task 3: Detection runner

**Files:** Create `bench/internal/run/{send.go,classify.go,detect.go}` and tests; modify `main.go`.

**Interfaces (Consumes** Tasks 1 and 2. **Produces):**
```go
package run
type Outcome string
const (Blocked Outcome="blocked"; Flagged="flagged"; RouteOnly="route-only"; Passed="passed"; Rejected="rejected"; Unknown="unknown"; NotSent="not-sent")
type Result struct{ CaseID, RequestID string; Status int; Outcome Outcome; Rules []string; LatencyUS int64; Reason string }
func NewClient(timeout time.Duration) *http.Client                       // never follows redirects, no proxy from environment, no cookies
func Send(ctx context.Context, c *http.Client, base *url.URL, cs cases.Case, requestID string) (status int, latency time.Duration, err error)
func Classify(status int, sendErr error, access *records.Access, ds []records.Decision) (Outcome, string)
func Detect(ctx context.Context, c *http.Client, base *url.URL, cs []cases.Case, idPrefix string, rps int) []Result  // status only; Outcome set by Join
func Join(rs []Result, access map[string]records.Access, ds map[string][]records.Decision) []Result
```
`Send` preserves the raw path and query bytes (`URL.Opaque`). Classification, in order: send error with no response → `Unknown` (client refused to encode → `NotSent`); no access record and status 400, 414, 431 or 501 → `Rejected`; no access record → `Unknown`; any decision `block` → `Blocked`; monitored with any rule not prefixed `AEG-ROUTE-` → `Flagged`; monitored with only `AEG-ROUTE-` rules → `RouteOnly`; status 403 without a decision → `Unknown`; otherwise `Passed`.

Command: `detect --cases f1,f2 --base URL --access f --decisions f --out results.jsonl [--rps 500] [--id-prefix b0000000-]`.

### Task 10: Remote mode

**Files:** Create `bench/internal/remote/{target.go,place.go,guard.go,run.go}` and tests, `bench/target.example.json` (host `waf.example.test`); modify `main.go`.

**Interfaces:**
```go
type Entry struct{ Method, Path string; Placements []string /* "query:q", "header:X-Note", "json:note" */; BenignStatus []int }
type Target struct{ BaseURL, RequestIDPrefix, Mode, HealthPath string; MaxRPS int; StopStatuses []int; Headers map[string]string; Allow []Entry } // snake_case JSON
func LoadTarget(path string) (Target, error)
func (t Target) Validate(confirmHost string, rps int) error
func Place(c cases.Case, t Target) (placed []cases.Case, reason string)
type Guard struct{ /* stop file, heartbeat file, last health */ }
func (g *Guard) Check(status int, benign bool, e Entry) (stop bool, reason string)
func (g *Guard) External(now time.Time) (stop bool, reason string)
func Run(ctx context.Context, o Options) ([]run.Result, string, error)    // second value: stop reason, "" if completed
```
Validation refuses: unknown JSON keys; scheme not `https` unless the host is loopback; user info; `confirmHost` not equal to `host[:port]` exactly; empty allow-list; a path that is not already normalised (`path.Clean(p)!=p`, `%`, `..`, `//`, or a query); `rps` over `MaxRPS` or below 1; missing prefix; `Mode` not `monitor` or `enforce`.

Placement keeps the entry's method and path exactly; only a case with a `Payload` and a query, header or JSON placement is rewritten into each matching entry; everything else is `NotSent` with a reason.

Stops: any 5xx; any status in `StopStatuses`; on a benign control, a status not in `BenignStatus` (including 403); health check not 200 (every 5 s); stop file exists; heartbeat file (when configured) older than 30 s or missing; failed redirect or transport errors on 3 consecutive requests. Each entry is proven with a benign control before any attack, and a control runs again every 50 requests. After a stop no new request starts.

Command: `remote --target f --confirm-host h --rps n --cases ... --out results.jsonl [--stop-file f] [--heartbeat-file f] [--limit 200]`, then `join --results f --access f --decisions f --out f` using the record formats of Task 2.
